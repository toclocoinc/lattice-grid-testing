### Added

- First release, 0.1.0: `@toclocoinc/lattice-grid-testing`, end-to-end test helpers on the grid's public DOM contract (ARIA roles and `data-*` attributes, no class names). `grid(root)` with `header`, `cell`, `row`, `rowCount`, `readCell`, `readRow`, `sortState`, `sort`, `filter`, `selectRange`, `editCell`, `scrollToRow`, `isIdle` and `waitForIdle`; root and item locators for the list, data view, Kanban, Gantt and calendar. Bindings for Playwright and Cypress (both optional peers) that drive gestures with real mouse and key input. Contract tests run in Chrome under both bindings against `@toclocoinc/lattice-grid` 1.112.0.
